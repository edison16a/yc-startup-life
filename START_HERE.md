# Start here

Open this folder with Claude Code (`claude`) and say: **"Begin."**

`CLAUDE.md` tells the agent what to do: run the completeness check, then carry out the `yc-knowledge-extractor` skill until every company is researched, the advice corpus is built, the knowledge files are written, the skills are finalized and the audit and backtest pass. It resumes from files, so you can stop and start.

Afterwards:
- Evaluate a startup: "Evaluate this startup: <description or link>".
- Find an idea: "Find me a startup idea."
