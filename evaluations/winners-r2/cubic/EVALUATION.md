## General assessment

Cubic sells AI code review into a category with a clear tailwind, since AI written code multiplies the pull requests that humans must read. The same tailwind drew GitHub, CodeRabbit, Greptile and Ellipsis, so a six person London team starts against funded rivals and a free bundled option. The seed estimate for the 19 month window is 0.50, close to the window adjusted cohort anchor, because the test showed that traction claims and hot sectors did not separate funded from unfunded companies. If a seed happens the most likely size is $3M to $6M. Series A inside the window is a long shot because the typical gap from batch start to A is about 28 months. The main killers are bundled review from GitHub and rivals with deeper pockets.

## Round by round: where and why it fails

### Getting into YC: 3.0%

**How we got the number.** Already accepted into the Spring 2025 batch, so this figure is the prior for a random applicant. YC says about 1 percent of applicants are accepted, with a third party range of 0.6 to 2 percent. I move it up to 3 percent for a technical team in a category with a clear tailwind (AI generated code needing review) and a working product, and keep it inside the 0.3 to 15 percent guard rail.

**Why it fails here.** YC would most plausibly say no because AI code review in early 2025 was already a funded category, with GitHub Copilot code review in preview, CodeRabbit and Greptile in YC, and no sign in the description of a unique wedge, user numbers or deep founder market fit beyond a 28 percent claim.

## Pros

- **Real and growing pain**: AI generated code raises review load, and GitHub itself built review into Copilot, which validates the need. (https://github.blog/changelog/2025-02-26-code-review-in-github-copilot-is-now-in-public-preview/)
- **Product beyond comments**: The human review view that reorders files and draws architecture diagrams is a differentiator from comment bots.

## Roadmap

### Get into YC

Show that review time falls for real teams.

1. Run a pilot with 10 teams and record time to merge before and after.
2. Publish the accepted comment rate per repo.

You know it worked when: Median time to merge down at least 20 percent across pilots.

### Reach Seed

Reach clear revenue growth in a narrow wedge.

1. Charge per seat from month two with 20 paying teams.
2. Win one lighthouse customer with 100 plus engineers.

You know it worked when: $30K to $50K monthly recurring revenue and weekly active reviewers above 60 percent.
